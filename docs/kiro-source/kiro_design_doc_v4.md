## I. 核心世界觀

### 1.1 最初的意識

**本質**:
- 造夢者
- 宇宙萬物的源頭
- 當前狀態:沉睡中

**位置**:
意識之海最深處

**特性**:
- 夢境創造:所有宇宙都是祂的夢
- 法則制定:五至寶是祂的工具
- 不可直視:凡人看到會瘋狂

**核心問題**:
> 「如果世界是夢,夢中的生命真的『活著』嗎?」

```yaml
身份: 最初的意識的「守夢者」
數量: 未知(至少100+)
職責:
  - 監控夢境穩定
  - 清除「變數」
  - 執行法則
武裝: 天使機甲
基地: 第十宇宙·永恆聖堂
```

**道主 = 觀察者**:
```yaml
真相: 道主就是被授權的觀察者
授權機制:
  - 觀察者選擇合適的生命
  - 賜予「法則碎片」
  - 綁定該宇宙
  - 成為道主(觀察者分身)

例外:
  - 第一宇宙:無道主(觀察者放棄)
  - 第九宇宙:道主失控
```

