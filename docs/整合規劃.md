# 《深淵尖塔》×《Kiro：觀測者之夢》整合規劃 v1

> 目標：把 Kiro 的世界觀與數值系統，融進現有的卡牌 Roguelike（殺戮尖塔類）骨架。
> 定位一句話：**「一名算命師，在輪迴中穿越全宇宙，用五術與卦象替眾生改命、對抗道主與觀察者。」**

---

## 0. 核心原則

1. **保留卡牌 Roguelike 骨架**：回合制、能量、格擋、抽牌、分支地圖、卡組構築、遺物、藥水、Boss。這套已完成且穩定，是遊戲的「動詞」。
2. **Kiro 提供世界觀與數值**：五術、五行、十宇宙、道主、輪迴、功德、靈魂磨損、難度。以「改皮＋加機制」融入，不是重寫。
3. **分階段上線**：每階段獨立可玩、可測試、可部署。改完 push → Vercel 自動更新。
4. **AI 對話/算命另開一條線**：需要後端 API 金鑰與費用，純靜態站做不到，列為 Phase 5（選配）。

## 3. 五術卡牌學派（Phase 1 核心）

把原本「攻擊/技能/能力」三分類，重構為**五術學派**，每派有主題與代表機制：

| 學派 | 主題 | 代表機制 | 對應原卡 |
|---|---|---|---|
| **山術**（修命/修性） | 自我修煉、防禦、爆發 | 格擋、力量、無敵(金剛不壞)、金屬化 | 防禦、金屬化、壁壘、屈伸 |
| **醫術**（治療/驅鬼） | 回復、解控、驅邪 | 回血、清除減益、對「惡靈」敵人加傷 | 甩開、喘息、治療藥水 |
| **命術**（知命/改命/遮天） | 改運、減益、操控命運 | 易傷、虛弱、力量竊取、改寫（重抽） | 重擊、勾拳、繳械、震盪波 |
| **相術**（風水/面相） | 環境增益、看穿 | 五行環境加成、佈陣、看穿意圖 | 怒火、幽靈護甲 |
| **卜術**（卜卦/趨吉/改變） | 預測、抽牌、卡序操控 | 抽牌、預知敵人意圖、趨吉避凶 | 柄擊、戰鬥恍惚、掘壕 |

> 實作：卡牌 `type` 由 `attack/skill/power` 擴充為帶 `school`（五術）＋ `kind`（攻擊/技能/能力，仍保留供規則判斷）。UI 用五色邊框呈現五術。

## 4. 五行相剋機制（Phase 1）

採用 Kiro 的相剋倍率表：

```
        金     木     水     火     土
金     1.0   1.5   0.75  0.75  1.25
木     0.75  1.0   1.25  0.75  1.5
水     1.25  0.75  1.0   1.5   0.75
火     1.5   1.25  0.75  1.0   0.75
土     0.75  0.75  1.25  1.25  1.0
```

- 每張攻擊卡有一個五行屬性；每個敵人有一個五行屬性。
- 傷害計算新增一步：`傷害 ×= 相剋倍率(卡屬性, 敵屬性)`（接在力量/易傷/虛弱之後）。
- UI：卡牌與敵人顯示五行圖示；相剋時傷害數字標記「剋！」。
- 相術可提供「五行環境」，全體同屬攻擊 +X%。

## 5. 多幕 / 十宇宙 / 道主（Phase 2）

- 地圖由**單幕**擴為**多幕**：打完幕王 → 進入下一宇宙（新地圖、新敵群、新事件）。
- 首波先做 **3 個宇宙**當可玩範圍（其餘設計預留）：

| 宇宙 | 主題 | 道主(幕王) | 敵群範例 |
|---|---|---|---|
| 一·歸墟 | 廢土拾荒 | （無道主，改為**荒獸·燭龍殘骸**） | 拾荒者、黑幫、機械警衛 |
| 二·武神界 | 武道熱血 | **奎托斯**（肉搏無敵，弱智謀） | 武者、角鬥士、精英武者 |
| 五·星際商盟 | 賭城資本 | **沃倫**（契約/財富操控） | 賞金獵人、海盜、AI 哨兵 |

- 道主 AI 用現有「意圖＋階段」框架擴充（Kiro 有 2–5 階段機制與弱點）。

## 6. 輪迴 meta 進度 + 難度（Phase 3）

- **輪迴**：死亡不再只是 Game Over，而是「本輪結束」，結算後可繼承：
  - 功德 50%、五術熟練度 100%、至寶/信物 100%（依 Kiro 繼承表）。
  - 熟練度可解鎖新卡/初始加成（類似殺戮尖塔的解鎖，但綁定五術）。
- **靈魂磨損**：每次輪迴 +1%，過高有負面（起手詛咒/減益）；可用功德/醫術/休息修復 → 提供長期張力。
- **難度模式**：故事/正常/困難/地獄/永恆＋鐵人模式，套用敵人傷害/HP、功德、死亡懲罰倍率。

---

## 7. 功德 / 遺物 / 至寶 / 藥水改皮（Phase 4）

- **雙資源**：Credits（商店買賣）＋ 功德（施展高階術法、修靈魂、觸發強效果）。
- **遺物改皮**：現有 15 遺物換成 Kiro 道具（賽博羅盤、血瓶→靈魂水晶…）。
- **至寶/法則碎片**＝**Boss 級稀有遺物**（時間長河＝每局一次重抽；命運之風＝改運…）。
- **世界變動率**：一條計量條，用「改命」類卡/事件會升高；到閾值召喚**觀察者**強敵亂入（高風險高回報）。

---

## 8. AI 對話 / 算命（Phase 5，選配，需後端）

- Kiro 的 API 規範（NPC 深度對話、卦象解讀、記憶繼承文本）需要 **Claude API 金鑰＋後端代理**，純靜態網站無法直接安全呼叫。
- 折衷方案：
  1. **先用本地模板**（Kiro 文件本就設計 80% 用本地模板），事件/算命走預寫多分支文本 → 純前端即可，先有味道。
  2. 之後要真 AI 生成，再加一個**極簡後端**（Vercel Serverless Function 代理 Claude API，金鑰放環境變數），這時就會用到你的 Vercel 專案設定。

---

## 9. 建議實作順序

```
P1  五術學派 + 五行相剋 + 主角/主題重皮        ← 先做，改動集中、最有感
P2  多幕(3 宇宙) + 道主 Boss + 新敵群
P3  輪迴 meta 進度 + 靈魂磨損 + 難度模式
P4  功德雙資源 + 至寶/法則碎片遺物 + 世界變動率
P5  事件/算命本地模板 →（選配）Claude API 後端
```

每個 Phase 都是一次可部署的更新。建議 **P1 先落地**，你玩過手感、確認方向，再往下疊。
