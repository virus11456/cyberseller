# 美術需求清單（給另一個 Cowork 視窗生圖用）

> 遊戲：《深淵尖塔 · 觀測者之夢》——算命師卡牌 Roguelike（依 Kiro 世界觀）。
> 目前程式全部用 emoji 佔位；下面每一項生好後，**放進對應資料夾、用指定檔名**，我就能接進遊戲替換。
> 生圖時把「風格」「配色」原樣貼進提示詞即可。

## 全域美術風格
- **主風格**：8-bit 像素 ＋ 賽博廢土 ＋ 東方修仙符號（羅盤、卦象、符籙、狐尾、機械義肢）。
- **畫面**：暗色 UI（背景 `#14121c`），霓虹點綴（金 `#f2c14e`、紅 `#d64550`、青 `#5aa9e6`、紫 `#9d6bd6`、綠 `#6fcf7f`）。
- **輸出**：PNG、透明背景（背景圖除外）、去鋸齒關閉（保留像素感）。

## 資料夾與命名
全部放在 `assets/art/`，子資料夾如下；檔名**小寫、底線分隔、就是下表的 id**。
