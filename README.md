# 群俠牌劫：衡陽風雨

《群俠牌劫：衡陽風雨》是一個武俠 roguelike 牌組構築遊戲原型。設計方向參考《金庸群俠傳》的開放江湖、門派武學、尋訪群俠與回合制戰鬥精神，再改寫成原創第一大關：少俠沿湘水古道追查黑帖，於衡陽擂台挑戰幕後壇主。

## 目前版本重點

- **第一大關完整主題**：目前大關為「衡陽風雨」，節點包含茶棚探聽、古道交鋒、鏢局疑雲、破廟調息與衡陽擂台。
- **回合制卡牌戰鬥**：每回合獲得真氣，使用手牌造成外傷、建立招架、觸發抽牌或累積悟性。
- **牌庫循環**：包含抽牌堆、棄牌堆與耗牌堆，抽牌堆空時會洗回棄牌堆。
- **敵人意圖**：介面會顯示敵人下一步行動，例如出招或凝勢。
- **原創武俠主題**：卡牌、敵人、資源與 UI 都改寫為原創江湖語彙，避免直接複製金庸小說角色、門派招式與劇情。

## 本機啟動

這個原型不依賴前端框架或打包器，可以直接用 Python 靜態伺服器啟動：

```bash
npm start
```

接著開啟：

```text
http://127.0.0.1:5173
```

## 第一大關：衡陽風雨

1. **茶棚探聽**：初遇江湖惡丐，教學基礎出牌、招架與敵人意圖。
2. **古道交鋒**：劫鏢刀客登場，開始要求玩家平衡進攻與防守。
3. **鏢局疑雲**：追查黑帖來源，透過戰利品擴充劍招、拳掌、內功或心法。
4. **破廟調息**：以行囊與內功感塑造補給感，目前用「破廟打坐」等牌呈現。
5. **衡陽擂台**：第一大關 Boss「黑帖壇主」，血量與招式循環更強，檢驗牌組成形程度。

## 玩法說明

1. 每場戰鬥開始時，玩家會從牌庫抽 5 張牌。
2. 第一回合因行囊效果有 4 點真氣，之後每回合 3 點真氣。
3. 點擊手牌可以消耗真氣並觸發卡牌效果。
4. 收招回合後，敵人會依照意圖出招或凝勢。
5. 擊敗敵人後，可以領取新卡牌與銀兩，並前往下一關。
6. 氣血歸零時可以重入江湖。
